# Breakout Game

A modern Breakout-style game built in Unity (C#), featuring custom visuals and polished gameplay.

## 🕹️ Play Online

Play instantly in your browser — no download required.

[![Play Breakout](https://img.shields.io/badge/Play%20Breakout-Unity-black?style=for-the-badge&logo=unity)](https://leonamlvs.github.io/breakout-game/)

[![Game screenshot](TemplateData/screenshot.png)](https://leonamlvs.github.io/breakout-game/)

## About

This project started as a learning exercise based on the **[Creating a Breakout game for beginners](https://www.youtube.com/watch?v=t_ahbdB0AnI)** tutorial.

After completing the core mechanics, I expanded it with my own visual style and refinements.

It represents an early milestone in my journey as a game developer and artist.

This repository contains the Unity WebGL export of the game.
